Footer

Casebound draws hardcover books with three.js and WebGL and puts an ordinary web page around them. It loads no model files and no pictures: the case, the pages and the cover of every book here are made from a few lines of data, and its light and motion were measured against a reference site, frame by frame.

Use it

Give the skill to a coding agent, or clone the repository and run the demo yourself.

npx skills add OthmanAdi/casebound --skill casebound

It needs Node 22 or newer and a browser with WebGL 2; without it the page shows the books as stills. Read the README for the rest.

The six books on this page are public-domain texts from Project Gutenberg.
